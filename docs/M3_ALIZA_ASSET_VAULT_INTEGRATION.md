## 2. API Contract

All endpoints reside under `/api/v1/assets` and require `Authorization: Bearer <session_token>`.

| HTTP Method | Path | Request Body | Response Status | Response Body | Description |
|---|---|---|:---:|---|---|
| `POST` | `/api/v1/assets` | `multipart/form-data` (`file`) | `201 Created` | `AssetResponse` | Upload, inspect magic bytes, encrypt with per-device key, and persist. |
| `GET` | `/api/v1/assets` | None | `200 OK` | `list[AssetResponse]` | List all assets owned by calling device (descending by date). |
| `GET` | `/api/v1/assets/{id}` | None | `200 OK` | `AssetResponse` | Retrieve detailed metadata for single asset. |
| `GET` | `/api/v1/assets/{id}/download` | None | `200 OK` | Binary stream | Check SHA-256 digest, decrypt in memory, return file attachment. |
| `PATCH` | `/api/v1/assets/{id}` | `{"filename": "..."}` | `200 OK` | `AssetResponse` | Rename asset filename without modifying ciphertext. |
| `DELETE` | `/api/v1/assets/{id}` | None | `204 No Content` | None | Delete database row and unlink ciphertext binary from disk. |

### Schema Definitions
- **`AssetResponse`**:
  - `id`: `UUID`
  - `original_filename`: `string`
  - `content_type`: `string | null`
  - `size_bytes`: `integer`

  - `encryption_status`: `string` (`"ENCRYPTED_XCHACHA20_POLY1305"`)

  - `updated_at`: `ISO8601 DateTime`

## 3. Cryptographic Design

### Cipher Selection: True XChaCha20-Poly1305
Unlike standard Python `cryptography` (which is restricted to 12-byte nonce ChaCha20-Poly1305), IPGuard uses `PyNaCl` C-bindings to libsodium:
- **Cipher:** `crypto_aead_xchacha20poly1305_ietf_encrypt` & `crypto_aead_xchacha20poly1305_ietf_decrypt`.
- **Key Length:** 32 bytes (256 bits).
- **Nonce Length:** 24 bytes (192 bits) generated by `secrets.token_bytes(24)`.
- **Authentication Tag:** 16 bytes (128 bits) appended to ciphertext.
- **Collision Bound:** Nonce reuse hazard is cryptographically negligible ($2^{-96}$).

### Key Derivation & Domain Separation (HKDF-SHA256)
Eliminates Aliza's static master key defect by cryptographically isolating tenants:
```python
def derive_asset_key(device_id: str, master_key: bytes | None = None) -> bytes:
    hkdf = HKDF(
        algorithm=hashes.SHA256(),
        length=32,
        salt=device_id.encode("utf-8"),
        info=b"ipguard-asset-vault-v1-xchacha20poly1305",
    )
    return hkdf.derive(master_key or settings.asset_vault_master_key_bytes)
```
- **Confidentiality Guarantee:** Ciphertexts belonging to Device A cannot be decrypted by Device B even under key leak or storage theft.
- **Fail-Closed Production:** `ASSET_VAULT_MASTER_KEY_B64` is validated during FastAPI lifespan; server refuses to start in production if absent or malformed.

### Associated Authenticated Data (AAD) Binding
To prevent ciphertext substitution between assets or accounts, ciphertext is bound to context:
```python
aad = f"v1|{device_id}|{str(asset_id)}".encode("utf-8")
```
Tampering with AAD or swapping ciphertext to another asset record causes Poly1305 decryption failure.

## 4. File Upload & Validation Security

1. **Filename Sanitization:** Rejects path traversal (`..`), directory separators (`/`, `\`), null bytes (`\x00`), and limits length to 255 chars.
2. **File Size Enforcement:** Rejects 0-byte uploads and enforces configurable max file size (default: 50 MB via `asset_vault_max_file_size_bytes`).
3. **Magic-Byte Signature Inspection:** Rejects executable binaries (`MZ`, `\x7fELF`, Mach-O, Java bytecode) even if disguised as images or PDFs. Resolves trusted MIME types from binary headers.
4. **Atomic Write Guarantee:**
   ```
   data -> encrypt -> write to {key}.tmp -> replace({key}) -> DB commit
   (On DB failure -> rollback -> unlink storage file)
   ```

## 5. Database Schema & Alembic Migration

Linear migration head applied on top of One-Time Device Enrollment:
- **Revision:** `0006_asset_vault`
- **Revises:** `0005_device_unregistered_status`
- **Table:** `assets`

  - `device_id`: `String(64)` (FK to `devices.device_id` `ON DELETE CASCADE`, indexed)
  - `original_filename`: `String(255)`
  - `storage_key`: `String(100)` (Unique)
  - `content_type`: `String(255)` (Nullable)
  - `size_bytes`: `BigInteger`
  - `nonce`: `String(64)`
  - `sha256_hash`: `String(64)`
  - `encryption_version`: `String(10)` (Default: `"v1"`)
  - `created_at`: `DateTime(timezone=True)`
  - `updated_at`: `DateTime(timezone=True)`
